  1. 核心功能：阻塞等待

让当前 Java 线程停下来卡住不动，一直等到刚才 exec 启动的 touch 系统进程完全运行结束、退出之后，代码才会继续往下执行。

  1. 不加 waitFor() 会有什么问题？

这里我们就需要了解一个概念叫做单例模式了 这个模式的意思是：

确保在整个程序运行期间，某一个类在内存里有且仅有一个实例（对象）存在。

由于Runtime类的特殊属性 导致了将Runtime类设置成了单例模式 另外再比如建立数据库连接时这种情况也很常见 因为建立数据库连接是一个很消耗的事 如果每次来一个用户就重新建立一遍连接那网站早就崩了 所有我们把数据库连接也设置成了单例模式
