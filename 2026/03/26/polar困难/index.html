  1. $_SERVER['QUERY_STRING'] 是什么？

过了检查之后，代码执行了： @parse_str($_SERVER['QUERY_STRING']);

我们要先搞懂 $_SERVER['QUERY_STRING']。 PHP 有时候会帮你把传进来的参数整理成数组（比如上面的 $_GET），但 $_SERVER['QUERY_STRING'] 非常野蛮，它根本不看 PHP 整理好的数组，而是直接去抓取你浏览器网址栏里 ? 后面的最原始的字符串。

所以，在这里，$_SERVER['QUERY_STRING'] 的值就是一串纯文本： "_POST[flag1]=8gen1&_POST[flag2]=8gen1"

  1. 致命的 parse_str() 函数（变量伪造机）

现在，这串原始文本被送进了 parse_str()。

parse_str(string $string) 的官方定义是：把字符串解析成多个变量，并设置到当前作用域中。 它的工作原理非常机械：它看到字符串里有 A=B，就会在内存里强行生成一个变量 $A，它的值是 B。如果看到 A[C]=B，它就会生成一个数组 $A，里面有个键叫 C，值是 B。

当它处理我们的字符串 _POST[flag1]=8gen1&_POST[flag2]=8gen1 时，极其恐怖的事情发生了： 它看到了 _POST 这个名字。它不管这个名字是不是 PHP 的系统保留字（比如 $_POST 是用来存 POST 请求数据的超全局变量），它直接在内存里强行重写了 $_POST 这个变量！

经过这一步，原本为空的 $_POST 数组，硬生生被它改写成了这样：

PHP

(注意：我们明明发的是 GET 请求，但通过 parse_str 的漏洞，我们成功伪造出了一个包含我们需要的数据的 POST 数组！)

  1. extract() 函数（拆包解压）

最后一步，代码执行了： extract($_POST);

extract(array $array) 的官方定义是：从数组中将变量导入到当前的符号表。 大白话就是：它会把数组里的“键名”直接变成“变量名”，把“键值”变成“变量值”。

因为我们在上一步已经把 $_POST 伪造成了包含 flag1 和 flag2 的数组，所以当 extract 处理它时：

  • 它看到数组里有个键叫 "flag1"，值是 "8gen1"，于是立刻在系统里生成了一行代码：$flag1 = "8gen1";
  • 它看到数组里有个键叫 "flag2"，值是 "8gen1"，于是又生成了一行：$flag2 = "8gen1";

到此为止，内存里真真切切地多出了 $flag1 和 $flag2 这两个独立的变量，并且它们的值都是 '8gen1'。

所以，紧接着的这句判断： if($flag1 == '8gen1' && $flag2 == '8gen1')

1️⃣ echo "..." （打包发货）

  • 作用： 这是 Linux 里极其伟大的发明。它像一条传送带，把左边 echo 吐出来的那一长串字符串，直接“喂”给右边的命令，而不是显示在屏幕上。

3️⃣ base64 -d （核心解码器）

  • 作用： base64 是 Linux 系统自带的编解码工具。后面的 -d 参数是 decode（解码）的缩写。
  • 它接收了管道传过来的那一长串代码，瞬间把它还原成了咱们上一回合讲的那段真正的 C 语言源码。

4️⃣ > /tmp/exp2.c （落地写盘）

  • 作用： > 是重定向符号，意思是“把前面解码出来的 C 语言代码，不要打印在屏幕上，而是写进一个文件里”。
  • 为什么选 /tmp 目录？（实战重点）： 在 Linux 系统中，你当前的身份是极其卑微的 www-data，你在这个系统的绝大多数地方都没有写文件的权限。但是，/tmp（临时文件夹）是 Linux 里唯一一个默认允许所有人（任何人）读写的地方。所以这里是存放咱们黑客武器的完美阵地！

而蚁剑的pty则是Web 层模拟，依赖目标语言（PHP/ASP/JSP）的执行能力，某些极端场景（如复杂信号、内核级操作）可能不如原生稳定，但日常命令、提权、运维足够用。

那为什么使用方法a就需要我们具有tty环境呢？

  • 原理解析： Payload A 的最后一句是 execve("/bin/sh", ...)。它的目的是在当前进程中“召唤”出一个一直运行的 Shell，等待你不断输入 ls、whoami 等命令。
  • 翻车现场： 如果你在蚁剑（没有 TTY）里执行 Payload A，蚁剑底层的 PHP 会帮你执行程序，程序确实召唤出了 /bin/sh 并且变成了 Root 权限，但是！这个 Root Shell 找不到可以输出画面的屏幕，也找不到可以接收你打字的键盘。 结果就是：网页一直转圈圈卡死，或者程序瞬间崩溃退出，你什么都看不到。
