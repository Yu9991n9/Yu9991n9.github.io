Google Hacking

Google hacking主要是通过借助谷歌搜索引擎的强大，借助特定的语法在庞大的互联网中搜索我们想要的信息

基本搜索

  • 逻辑与：and
  • 逻辑或： or
  • 逻辑非： -
  • 完整匹配：”关键词”
  • 通配符：* ?

语法

intext

寻找网页正文中存在关键字的页面：

intitle

寻找标题中存在关键字的网页

allintitle

其实就是支持多个关键词一起搜索的intitle

就比如这里我要搜索一个标题既有后台登录，同时也有管理员的网站

inurl

顾名思义就是去找url里面存在关键字的网站，例如：inurl:Login 将返回url中含有 Login 的网页

allinurl

和上面allintitle一样，支持搜索多个关键词的URL

site

指定访问的站点，例如： site:http://baidu.com inurl:Login 将只在http://baidu.com 中查找url中含有 Login的网页

filetype

指定访问的文件类型，例如：site:http://baidu.com filetype:pdf 将只返回http://baidu.com站点上文件类型为pdf的网页

link

link:

指定链接的网页，例如：link:http://www.baidu.com 将返回所有包含指向 http://www.baidu.com 的网页

​ 这个命令和site的区别就在于，一个向外一个向内，site是=限定目标信息的来源，去目标网址下面找而link呢则是向外找哪些网站链接了目标网站

related

相似类型的网页，例如：related:http://www.xjtu.edu.cn 将返回与 http://www.xjtu.edu.cn 相似的页面，相似指的是网页的布局相似

cache:

网页快照，谷歌将返回给你他存储下来的历史页面，如果你同时制定了其他查询词，将在搜索结果里以高亮显示，例如：cache:http://www.hackingspirits.com guest ，将返回指定网站的缓存，并且正文中含有guest

info:

返回站点的指定信息，例如：info:http://www.baidu.com 将返回百度的一些信息

define:

返回某个词语的定义，例如：define:Hacker　　将返回关于Hacker的定义

phonebook:

电话簿查询美国街道地址和电话号码信息。例如：phonebook:Lisa+CA 将返回名字里面包含Lisa并住在加州的人的所有名字

利用 Index of 语法去发现允许目录浏览的web网站，就像在本地的普通目录一样。下面是一些有趣的查询：

  1. 核心本质
  • 不是黑客指令： 它只是配置错误的 Web 服务器（忘记放 index.html 且开启了目录浏览）自动生成的网页的默认标题。
  • 相当于什么： 相当于别人把存放机密文件的 U 盘，毫无防备地插在了公共电脑上。
  1. 搜索公式

万能句式：intitle:"index of" "你要找的特定文件或文件夹名" (注意：务必使用双引号，强制谷歌进行一字不差的精确匹配)

  1. 实战寻宝指南
  • 找源代码 (终极杀器)：
    • intitle:"index of" ".git" (找 Git 源码库，直接扒全站代码)
    • intitle:"index of" ".svn" (找 SVN 源码库)
  • 找数据库 & 备份 (直接拿数据)：
    • intitle:"index of" "database.sql" (找 SQL 导出文件)
    • intitle:"index of" "users.db" (找 SQLite 数据库文件)
    • intitle:"index of" "backup.zip" | "wwwroot.tar.gz" (找网站源码打包备份)
  • 找配置文件 & 密码 (拿权限)：
    • intitle:"index of" ".env" (找环境变量，里面通常有数据库密码或云密钥)
    • intitle:"index of" "id_rsa" (找 SSH 私钥，尝试免密登录服务器)
    • intitle:"index of" "password.txt" (最简单粗暴的密码本)
  • 找敏感日志 (找线索和后台接口)：
    • intitle:"index of" "error.log" (报错日志，常包含绝对路径和 SQL 报错)
    • intitle:"index of" "access.log" (访问日志，可以分析出隐藏的 API 接

第一种的ip查询就是知道了网站的具体ip，这种就是最精确的ip搜索

第二种就是就是扫c段

这是什么： 这是渗透测试里最常用的高阶技巧之一。这里的 /24 叫做 CIDR（无类别域间路由） 表示法。它不再是搜一个 IP，而是搜一整个网段（共 256 个 IP）。

什么是 C段 (C段渗透)： /24 意味着 IP 地址的前 24 位（即前三个数字 220.181.111）是固定不变的，只有最后一个数字在变（从 0 变到 255）。所以这条命令实际上是在搜从 220.181.111.0 到 220.181.111.255 这 256 个 IP 上的所有资产。

就比如127.0.0.1里面，127就是a段，0就是b段，再往后的那个0就是c段了

实战场景 (为什么黑客爱扫C段？)： 企业的 IT 部门在购买公网 IP 时，通常是一段一段买的。如果你发现目标公司的官网在 220.181.111.15，并且它的防御非常变态，你根本打不进去。怎么办？ 你可以去搜它的 C段！很可能 .16 是他们无人打理的测试服务器，.17 是有漏洞的旧版 OA 系统，.18 是员工的 VPN 入口。只要拿下同网段的任何一台边缘机器，你就可以以此为跳板，直接打入企业内网（内网漫游）。

子域名收集

首先要知道子域名是什么

子域名是指顶级域名（一级域名）的下一级域名，如mail.qq.com和www.qq.com都是qq.com的子域。从旁站查找漏洞往往比主站容易，因此子域名信息的收集显得尤为重要。其中qq.com就是这一系列子域名的主域名

手动查询

2. 查找目标所有关联域名

2.1 备案查询

  • 官方备案网站：如工信部ICP备案系统、chinaz、等，通过主域名查备案，获得域名所属公司名称，再搜索该公司名称以获取其所有注册域名。

2.2 企业关系查询

  • 企业信息查询平台：如天眼查、爱企查、企查查等，通过查看股权穿透图来查找子公司，并收集其子公司的域名。

2.3 Whois反查关联域名

  • Whois查询网站：如Whois.chinaz.com，通过同一公司的域名可能使用同一邮箱注册的信息进行反查。

2.4 官网等方式查关联域名

  • 官网架构图：目标企业的官网有时会列出子公司的介绍和官网链接，通过这些信息可以直接获取子域名。

3. 收集子域名

3.1 证书透明度查询

  • 证书透明度查询网站：如crt.sh、Censys、SSLmate、Facebook CT等，由于许多企业域名使用HTTPS协议，TLS证书中通常包含域名信息，可以通过查询证书透明度来收集子域名。

3.2 在线子域名查询网站

  • 子域名查询网站：如SecurityTrails、IP138、Chinaz、dnsscan.cn等，输入域名即可获取子域名列表。

3.3 威胁情报平台

  • 威胁情报平台：如ThreatBook、VirusTotal、AlienVault OTX、RiskIQ、ThreatMiner等，通过这些平台可以收集到目标组织的子域名信息。

3.4 搜索引擎

  • 搜索引擎语法：使用Google等搜索引擎，结合site:语法（如site:example.com）来限制搜索结果，从而获取子域名信息。

3.5 爬虫爬取

  • 爬虫技术：通过编写爬虫程序，爬取目标网站的所有页面、robots.txt文件、crossdomain.xml文件、sitemap文件等，从中筛选出子域名。

3.6 DNS记录查询

  • 工具如nslookup：使用nslookup等工具查询域名的SRV、NS、MX、TXT等记录，以收集子域名信息。但这种方法收集的域名有限。

3.7 自动化工具

  • 自动化工具：如Subfinder、OneForAll、Layer子域名挖掘机等，这些工具通过多个API和字典枚举的方式自动化收集子域名。

3.8 DNS历史记录查询

  • DNS历史记录查询服务：如SecurityTrails、http://DNSdumpster.com、WhoisXML、PassiveTotal等，通过查询过去DNS解析记录的服务，可以查找目标组织过去使用过的子域名。这种方法有时能发现已被删除但仍解析到目标组织的子域名。

  • 3.9 从JS文件发现子域名
  • JS文件分析：许多网站在JS文件中会包含子域名的信息，通过分析JS文件可以挖掘出子域名。可以使用专门的脚本或工具（如JSFinder）来自动化这一过程。
  • 3.10 子域名爆破
  • 子域名爆破工具：使用如Sublist3r、Amass、Subfinder、Assetfinder等工具，通过字典或其他方法生成可能的子域名列表，并对列表中的每个子域名进行DNS解析以确定其是否存在。
  • 工具推荐
  • Subfinder：集成了多个API接口进行自动化搜索子域名信息，收集速度快。
  • OneForAll：功能强大的子域收集工具，支持多种搜索方式。
  • Layer子域名挖掘机：扫描结果依赖于字典的强大性，适合使用自定义字典进行深度挖掘。
  • Sublist3r：简单易用的子域名枚举工具，支持多线程枚举。
  • KSubdomain：无状态子域名爆破工具，支持高并发DNS爆破，速度快。
  • 批量处理
  • 对于有大量域名需要查找子域名的情况，可以通过请求API接口或使用高效的爆破工具（如KSubdomain）进行处理。但需要注意控制请求频率，频率过高会被判定为ddos攻击！

其中那个-l参数就是说去那个文件里面，把文件里面包含的所有网站都测试一遍，但是这个也有需要注意的地方：

首先这个参数只认纯文本，也就是.txt的东西，并且一行只能有一个目标例如：

带不带 http:// 都有讲究

你的文本里写 jwgl.cuit.edu.cn，还是写 http://jwgl.cuit.edu.cn，httpx 处理起来是不一样的：

  • 不带前缀（推荐）： 如果你的文件里只有纯域名（比如 cuit.edu.cn），httpx 会非常聪明地同时去探测它的 http://80端口 和 https://443端口。哪怕它关了 HTTP 开了 HTTPS，也绝对漏不掉。
  • 带了前缀： 如果你的文件里写死了 https://cuit.edu.cn，那 httpx 就只会去敲 HTTPS 的门，不管其他的。

一个满配命令：

.单个目标探测

Bash
httpx.exe -u https://www.example.com //-u探测网站基本信息

2.批量目标扫描

Bash
httpx.exe -l targets.txt //-l对文件中的目标进行扫描，即扫描多个目标

3.自定义请求头

Bash
httpx.exe -u https://www.example.com -H “User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64)”
//-H使用自定义请求头

4.设置超时时间

Bash
httpx.exe -u https://www.example.com -timeout 10 //-timeout设置超时时间

5.cdn和服务器信息

Bash
httpx.exe -u https://www.example.com -cdn -web-server
//-cdn显示cdn信息，-web-server显示web服务器信息

6.状态码 过滤

Bash
httpx.exe -l .\url.txt -fc 403,404
//-fc过滤指定状态码

7.配置随机UA头部

Bash
httpx -u https://www.example.com -random-agent -no-decode
//–random-agent启用随机User-Agent头， -no-decode避免解码响应体

8.显示状态码信息

Bash
httpx -l url.txt -sc //-sc显示状态码

httpx.exe -l url.txt -cdn -web-server -fc 404,500 -o output.txt -random-agent -timeout 10

//批量二：探测成功的url输出
